# 家計簿アプリ

GitHub Pagesで公開するための単一HTMLアプリです。

## 使い方

1. このリポジトリに `index.html` をアップロードします。
2. GitHubのリポジトリ画面で Settings → Pages を開きます。
3. Branch を `main`、folder を `/root` にして保存します。
4. 発行されたURLをiPhoneのSafariで開きます。
5. 共有ボタンから「ホーム画面に追加」します。

## 注意

- データはブラウザの localStorage に保存されます。
- iPhoneとPCで自動同期はされません。
- Safariの履歴・Webサイトデータを削除すると、家計簿データも消える可能性があります。
